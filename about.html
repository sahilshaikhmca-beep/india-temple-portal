About this project

This portal presents structured information about Indian temples and pilgrimage destinations in a simple, easy-to-use interface, to improve access to heritage and pilgrimage information.

Built as a static HTML, CSS and JavaScript website for GitHub Pages. Temple data is stored in static/js/data.js and is easy to extend. Always confirm timings, dates and travel conditions with official sources before you travel.

Temple information is available through the website's search and filter interface.
