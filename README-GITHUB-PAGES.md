# India Temple Heritage & Pilgrimage Portal (GitHub Pages)

This is the static GitHub Pages version of the original Flask project.

## Publish
1. Copy the contents of this folder into the root of your `india-temple-portal` GitHub repository.
2. Commit the changes to `main`.
3. In Settings → Pages, select Deploy from a branch, `main`, and `/(root)`.
4. Open: https://sahilshaikhmca-beep.github.io/india-temple-portal/

## Features
- 9 temple records and 3 pilgrimage circuits
- Search by temple name, city, deity or category
- Filter temples by state
- Individual temple detail pages
- Responsive layout using the supplied CSS styling

The Flask backend and `/api/temples` endpoint are not included because GitHub Pages only hosts static files.
